# STM32 Embedded Learning Log

> 个人嵌入式学习日志：从 STM32 入门到独立完成 PCB 投板的全过程记录。

## 项目目标

通过 6 个月的系统学习，从 C 语言基础起步，最终独立完成一个
**柔性传感器信号采集 + BLE 无线传输**的端到端嵌入式项目。

## 技术栈

- **MCU**: STM32F103C8T6
- **工具链**: STM32CubeIDE + HAL
- **RTOS**: FreeRTOS（计划）
- **PCB**: KiCad 2 层板（计划）
- **通信**: UART / I2C / SPI / BLE
